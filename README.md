# GoalStyle | E-commerce de Camisas de Seleções

**Projeto Full Stack | Desenvolvimento Web**

O **GoalStyle** é um projeto acadêmico de e-commerce inspirado na Copa do Mundo FIFA 2026, desenvolvido com o objetivo de simular uma loja virtual especializada na venda de camisas de seleções nacionais.

A aplicação foi construída com **front-end e back-end integrados**, reunindo uma interface responsiva, funcionalidades de comércio eletrônico e recursos interativos para proporcionar uma experiência de navegação próxima à de uma loja virtual real.

## Funcionalidades

- **Catálogo de produtos:** exposição de camisas de diferentes seleções nacionais.
- **Filtro por marcas:** navegação e organização dos produtos.
- **Carrinho de compras:** seleção e gerenciamento dos produtos escolhidos.
- **Modo Dark/Light:** alternância entre temas claro e escuro.
- **Mapa interativo:** visualização da localização das lojas utilizando Leaflet.
- **Integração com WhatsApp:** canal de contato e atendimento ao cliente.
- **Layout responsivo:** adaptação da interface para dispositivos móveis e desktops.
- **Integração Front-end e Back-end:** comunicação entre a interface e o servidor da aplicação.

## Arquitetura do Projeto

O desenvolvimento foi estruturado com separação entre a interface visual e a lógica do servidor.

O **front-end** é responsável pela apresentação dos produtos, interações do usuário, navegação e experiência visual.

O **back-end**, desenvolvido em Node.js, compõe a estrutura de servidor da aplicação e sua integração com o front-end.

## Objetivo e Aprendizados

O projeto teve como objetivo aplicar, na prática, conhecimentos de desenvolvimento web Full Stack, desde a construção de interfaces até a implementação e integração de funcionalidades no servidor.

Durante o desenvolvimento, foram trabalhados conceitos de organização de código, manipulação do DOM, responsividade, interatividade e comunicação entre diferentes camadas de uma aplicação web.
